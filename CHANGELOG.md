# Changelog

## First public release — YTDLP 2.0.0 · Host 1.0.0 · Extension 1.0.0

- FlyleafLib NuGet dependency with minimum version 3.11.16.
- yt-dlp/Deno shared installation and staged self-updates.
- Shared Native AOT host, installed on demand when browser cookies are enabled.
- Chrome/Brave normal/private cookie bridge with per-application approval.
- Browser-cookie protocol v3; protocol compatibility checked independently of host file version.
- GitHub Actions builds and publishes separately versioned component assets, metadata and checksums.
